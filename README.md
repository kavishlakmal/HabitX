# HabitX – Habit Tracking Android App

An Android app to help users build and maintain healthy daily routines.

## Features
- Habit tracking with circular progress indicators
- Mood journaling with line chart visualization
- Water intake tracker with customizable reminder intervals
- Push notifications with vibration support
- Settings screen with data reset and app sharing

## Tech Stack
- Kotlin
- Android SDK
- Material Design 3
- WorkManager (background reminders)
- MPAndroidChart (mood trend chart)
- SharedPreferences (local data storage)
